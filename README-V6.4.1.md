# Sri Cine Hub V6.4.1 — Document Close Action

- Added a visible `✕ Close` action to receipt document screens.
- Applied the same close behavior consistently to quotation and supplier RFQ document screens.
- Receipt closes to `/admin/receipts`; quotations to `/admin/quotations`; supplier RFQs to `/admin/supplier-rfqs`.
- Existing Back, Print / Save PDF, Download PDF, Share and WhatsApp actions are retained.
