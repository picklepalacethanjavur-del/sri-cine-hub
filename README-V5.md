# Sri Cine Hub V5 — Quotation Workflow

Major changes:
- Separate Quote Requests and Quotations navigation
- Quote Requests organized into Received/Pricing vs Generated/Completed
- Clickable quotation history
- Full itemized pricing workspace
- Internal rate shown to staff only
- Per-line quoted rate, quantity, days, and description editing
- Add cameras, accessories, kits, and custom charges
- Optional overall discount, tax, and other charges
- Draft vs generated quotation status
- Existing quotations can be reopened and edited
- Dedicated customer-facing printable quotation
- Real Print / Save PDF button using browser print dialog
- Internal rate snapshot stored with every quotation line
- Customer de-duplication by phone during quote creation
- Accepted quotation can be converted into a reserved booking

Database migration `quotation_editor_v5` has already been applied to the Sri Cine Hub Supabase project.

Deploy this project only when you are ready; the current V4 deployment does not need to be changed while testing.
